# Random Quote Generator

**Автор:** [Факов Айдар]
**Язык:** Python 3.8+
**Библиотеки:** tkinter (входит в стандартную библиотеку), json

## Описание проекта

Графическое приложение для генерации случайных цитат с возможностью:
- Сохранения истории в файл JSON.
- Фильтрации цитат по автору и теме.
- Добавления собственных цитат с проверкой ввода.
- Загрузки истории при запуске.

## Запуск

1. Установите Python 3.8+ (если не установлен).
2. Скачайте или склонируйте репозиторий.
3. Запустите: `python main.py`

## Использование

- **Сгенерировать цитату:** нажмите кнопку «Сгенерировать цитату».
- **Фильтрация:** введите автора или тему и нажмите «Применить фильтр».
- **История:** все сгенерированные и добавленные цитаты отображаются в списке.
- **Добавить цитату:** заполните поля в разделе «Добавить новую цитату» и нажмите «Добавить».

## Примеры использования

1. Запустите приложение.
2. Нажмите «Сгенерировать цитату» — появится случайная цитата.
3. Введите «Мотивация» в фильтр по теме — в истории останутся только мотивационные цитаты.
4. Добавьте свою цитату через форму.
